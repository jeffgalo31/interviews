# AWS Cloud

The role lists Lambda, RDS, ECS, DynamoDB, API Gateway, and S3. These exercises explain appropriate boundaries and access patterns instead of treating the services as interchangeable.

- [Event-Driven Data API](event-driven-data-api.md): integrate all six named AWS services with least-privilege security and reliable ingestion.
- [DynamoDB Access Patterns](dynamodb-access-patterns.md): choose keys from known queries and compare with relational storage.
