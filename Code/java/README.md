## 📖 How to study one exercise

1. Read the problem in the exercise's `README.md` and try solving it yourself.
2. Check the **🧪 Example** section: the exact input your program gets and the output it must print.
3. Read **💡 Solution**: the key idea first, then the code you write and how it works.
4. Run `Solution.java` (it uses the sample input when you don't type any).
5. Submit `Solution_hackerrank.java` on HackerRank and mark it ✅ below.

## ▶️ Running

Open the `interviews` folder (or this `java` folder) in VS Code with the Extension Pack for Java, open a `Solution.java` and click **Run** above `main`. From a terminal in this folder:

```
java src/introduction/java_if_else/Solution.java                 # uses the sample input
printf '24\n' | java src/introduction/java_if_else/Solution.java  # your own input
```

> [!NOTE]
> VS Code may list errors for the `Solution_hackerrank.java` files: they have no `package` line on purpose (that's how HackerRank needs them). They don't stop the `Solution.java` files from running.
